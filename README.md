## Sobre o projeto

Este projeto consiste no desenvolvimento de um site pessoal de currículo e portfólio utilizando HTML5 e CSS3 puro.

O objetivo é apresentar o meu percurso académico, competências, projetos, interesses e informações de contacto.

O projeto foi desenvolvido sem frameworks CSS e sem JavaScript.

---

## Estrutura do site

### Início — index.html

Apresenta:

- Nome e fotografia;
- Breve apresentação pessoal;
- Áreas de interesse;
- Botões de navegação;
- Vídeo de apresentação;
- Áudio de apresentação.

### Currículo — about.html

Apresenta:

- Perfil académico;
- Formação;
- Competências técnicas;
- Competências pessoais;
- Tabela de conhecimentos.

### Portfólio — portfolio.html

Apresenta projetos e áreas de aprendizagem relacionados com:

- Desenvolvimento Web;
- Programação Java;
- Bases de Dados;
- Redes de Computadores.

Os projetos apresentados têm finalidade académica.

### Hobbies — hobbies.html

Apresenta interesses relacionados com:

- Tecnologia;
- Aprendizagem;
- Programação;
- Desenvolvimento Web.

### Contacto — contact.html

Contém um formulário HTML5 com:

- Nome;
- Email;
- Telefone;
- Data;
- Número;
- Select;
- Radio;
- Checkbox;
- Upload de ficheiro;
- Textarea;
- Validação nativa HTML5.

## Tecnologias utilizadas

### HTML5

Foram utilizadas tags semânticas como:

- `<header>` — cabeçalho;
- `<nav>` — navegação;
- `<main>` — conteúdo principal;
- `<section>` — secções;
- `<article>` — conteúdos independentes;
- `<aside>` — conteúdo complementar;
- `<footer>` — rodapé;
- `<figure>` — conteúdo visual;
- `<figcaption>` — legenda de imagens;
- `<table>` — apresentação de dados;
- `<form>` — formulário;
- `<video>` — vídeo;
- `<audio>` — áudio.

### CSS3

Foram utilizados:

- Variáveis CSS;
- Flexbox;
- CSS Grid;
- Media queries;
- Pseudo-classes;
- Pseudo-elementos;
- Seletores de atributo;
- Seletores de filho;
- Seletores de irmão adjacente;
- Transições;
- Animações;
- Gradientes;
- Sombras;
- Unidades relativas;
- `position: sticky`.

---

## Responsividade

O site foi desenvolvido com abordagem mobile-first.

Foram utilizadas media queries para adaptar o layout a:

- Telemóveis;
- Tablets;
- Ecrãs maiores.

---

## Multimédia

O projeto utiliza:

- Imagens locais;
- Vídeo local em formato MP4;
- Áudio local em formato MP3.

---

## Formulário

A validação do formulário é feita através dos recursos nativos do HTML5, utilizando atributos como:

- `required`;
- `pattern`;
- `min`;
- `max`;
- `minlength`;
- `maxlength`;
- `accept`.

Não foi utilizado JavaScript para validação.
